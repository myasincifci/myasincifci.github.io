# My Personal Blog

This repository contains my personal blog, built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

## Project Structure

- `content/`: Contains the markdown files for posts.
- `themes/`: Contains the PaperMod theme.
- `hugo.yml`: Site configuration.
- `legacy_project/`: Contains the previous project files (Python scripts, etc.).

## Running Locally

1.  **Install Hugo**: Ensure you have Hugo installed (extended version recommended).
2.  **Run Server**:
    ```bash
    hugo server
    ```
3.  **Visit**: Open `http://localhost:1313` in your browser.

## Deployment

This site is ready to be deployed to GitHub Pages.
